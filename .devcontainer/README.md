# Dev Container для RP2350 Multi-UART

Эта директория содержит конфигурацию для разработки в изолированном Docker контейнере.

## Что включено

- **Ubuntu 22.04** - базовый образ
- **ARM GCC Toolchain** - компилятор для ARM микроконтроллеров
- **CMake** - система сборки
- **Git** - система контроля версий
- **Python 3** - для инструментов Pico SDK
- **Pico SDK** - автоматически клонируется при первом запуске

## Использование

1. Откройте проект в VS Code
2. Нажмите `F1` → "Dev Containers: Reopen in Container"
3. Дождитесь сборки контейнера (первый раз может занять несколько минут)
4. После загрузки все инструменты будут готовы к использованию

## Настройки VS Code

Контейнер автоматически настраивает:
- Пути к заголовочным файлам Pico SDK
- Компилятор ARM GCC
- CMake для сборки проекта
- Расширения для отладки Cortex-M

## Переменные окружения

- `PICO_SDK_PATH` - путь к Pico SDK (автоматически устанавливается)

## Ручная сборка образа

Если нужно собрать образ вручную:

```bash
docker build -t rp2350-dev .devcontainer
```
